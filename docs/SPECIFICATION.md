# LumiPop - 夜間光と人口の関係性可視化アプリ 仕様書

## 1. 概要

### 1.1 プロジェクト名
**LumiPop** (Luminosity + Population)

### 1.2 目的
世界各地の夜間光（衛星画像から取得）と人口データの関係性をインタラクティブに可視化するWebアプリケーション。

### 1.3 ターゲットユーザー
- 企業の採用担当者（ポートフォリオ閲覧者）

### 1.4 公開方法
- GitHub Pages (github.io) での静的サイトホスティング

---

## 2. 機能要件

### 2.1 地図表示機能
| 機能 | 説明 | 優先度 |
|------|------|--------|
| インタラクティブ地図 | ズーム・パン操作が可能な世界地図 | 必須 |
| 夜間光レイヤー | 衛星画像から取得した夜間光強度を表示 | 必須 |
| 人口レイヤー | 人口密度をヒートマップまたはコロプレスで表示 | 必須 |
| レイヤー切り替え | 各レイヤーの表示/非表示を切り替え | 必須 |

### 2.2 空間単位の選択
| 単位 | 説明 | 優先度 |
|------|------|--------|
| 都市単位 | 主要都市ごとの集計値 | 必須 |
| H3インデックス | Uber H3による六角形グリッド（解像度選択可能） | 必須 |
| 国単位 | 国ごとの集計値 | 任意 |

### 2.3 関係性の可視化
| 機能 | 説明 | 優先度 |
|------|------|--------|
| 散布図 | 夜間光 vs 人口の散布図表示 | 必須 |
| 回帰線 | 対数回帰線のオーバーレイ | 必須 |
| 相関係数表示 | ピアソン・スピアマン相関係数 | 必須 |
| 決定係数 (R²) | 回帰モデルの説明力表示 | 必須 |

### 2.4 外れ値の扱い
| 機能 | 説明 | 優先度 |
|------|------|--------|
| 外れ値検出 | IQR法による自動検出 | 必須 |
| 視覚的区別 | 外れ値を別色でハイライト | 必須 |
| 除外オプション | ユーザーが外れ値の表示/非表示を選択 | 必須 |
| ツールチップ | 外れ値にホバー時に詳細情報表示 | 任意 |

### 2.5 インタラクション
| 機能 | 説明 | 優先度 |
|------|------|--------|
| 地域選択 | 地図クリックで地域を選択 | 必須 |
| フィルタリング | 人口範囲・光強度範囲でフィルタ | 任意 |
| 詳細パネル | 選択地域の詳細情報表示 | 必須 |

## 3. データ仕様

### 3.1 夜間光データ
| 項目 | 内容 |
|------|------|
| データソース | NASA VIIRS DNB (Black Marble) |
| 形式 | GeoTIFF → JSON変換（事前処理） |
| 解像度 | 約500m (15 arc-second) |
| 時点 | 最新の年次合成データ（2022年または2023年） |
| ライセンス | パブリックドメイン |

**代替データソース:**
- Earth Observation Group (EOG) VIIRS Nighttime Lights

### 3.2 人口データ
| 項目 | 内容 |
|------|------|
| データソース | WorldPop または GPW (Gridded Population of the World) |
| 形式 | GeoTIFF → JSON変換（事前処理） |
| 解像度 | 約1km |
| 時点 | 2020年推計値 |
| ライセンス | Creative Commons (CC BY 4.0) |

### 3.3 行政境界データ
| 項目 | 内容 |
|------|------|
| データソース | Natural Earth |
| 形式 | GeoJSON |
| 詳細度 | 1:10m (高解像度) |
| ライセンス | パブリックドメイン |

### 3.4 都市データ
| 項目 | 内容 |
|------|------|
| データソース | GeoNames または Natural Earth populated places |
| 形式 | GeoJSON |
| 対象 | 人口10万人以上の都市 |

## 4. 技術仕様

### 4.1 フロントエンド
| 項目 | 選定技術 | 理由 |
|------|----------|------|
| フレームワーク | React 18 + TypeScript | 型安全性、コンポーネント再利用性 |
| ビルドツール | Vite | 高速ビルド、GitHub Pages対応 |
| 地図ライブラリ | deck.gl + Mapbox GL JS | H3対応、高性能レンダリング |
| チャートライブラリ | Recharts または D3.js | 散布図・回帰線描画 |
| UIコンポーネント | Tailwind CSS | 軽量、カスタマイズ性 |
| 状態管理 | Zustand | 軽量、シンプル |

### 4.2 データ処理（事前処理）
| 項目 | 選定技術 | 理由 |
|------|----------|------|
| 言語 | Python 3.11+ | 地理空間データ処理の豊富なライブラリ |
| 地理空間処理 | Rasterio, GeoPandas | GeoTIFF読み込み、空間演算 |
| H3変換 | h3-py | Uber H3インデックス生成 |
| 統計処理 | NumPy, SciPy | 相関係数、回帰分析 |

### 4.3 ホスティング
| 項目 | 内容 |
|------|------|
| プラットフォーム | GitHub Pages |
| デプロイ | GitHub Actions による自動デプロイ |
| ドメイン | `<username>.github.io/lumipop` |

### 4.4 地図タイル
| 項目 | 内容 |
|------|------|
| ベースマップ | Mapbox (無料枠) または MapTiler |
| スタイル | ダークテーマ（夜間光を際立たせる） |

## 7. 統計手法

### 7.1 相関分析
| 指標 | 数式 | 用途 |
|------|------|------|
| ピアソン相関係数 | r = Σ(x-x̄)(y-ȳ) / √[Σ(x-x̄)²Σ(y-ȳ)²] | 線形関係の強さ |
| スピアマン順位相関 | ρ = 1 - 6Σd²/n(n²-1) | 単調関係（外れ値に強い） |

### 7.2 回帰分析
| モデル | 数式 | 用途 |
|------|------|------|
| 対数回帰 | log(y) = a × log(x) + b | べき乗関係のモデル化 |
| 決定係数 | R² = 1 - SS_res/SS_tot | モデルの説明力 |

### 7.3 外れ値検出
| 手法 | 基準 | 適用 |
|------|------|------|
| IQR法 | Q1 - 1.5×IQR 〜 Q3 + 1.5×IQR | 主要な検出方法 |
| 対数変換 | log(value + 1) | スケール正規化 |
